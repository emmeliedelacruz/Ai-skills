# Video Style Onboarding

Use this reference on the first run or whenever the user wants to change the visual treatment.

## Fast onboarding

Ask only what is needed to make the first visual decision.

Start with:

"Before we choose clips, let's lock the visual system. You can either upload a screenshot/example you like, or I can show you 4 style directions for headline, captions, and end screen."

Do not ask the user to answer a long brand questionnaire before showing anything visual.

## If the user uploads a reference

Extract the observable design rules:
- headline placement
- text case and weight
- headline container shape and opacity
- border, glow, gradient, or shadow
- highlighted words
- caption placement
- caption case, outline, shadow, or background
- maximum lines
- approximate spacing / safe zone
- end-screen treatment if visible

Summarize the inferred profile in a short list and resolve only genuine ambiguity.

## If the user wants options

Create 4 mockups using the same sample headline and caption copy.

Good option spread:
1. Clean brand card headline + simple outlined captions
2. Editorial oversized headline + minimal captions
3. Creator/TikTok headline + bold outlined captions
4. Minimal no-box headline + restrained captions

Keep the underlying frame comparable across all four options.

Do not use the user's likeness unless they have provided an image of themselves in the current conversation. A generic presenter or neutral video still is sufficient for style selection.

## Default style when the user has no preference

Use a clean performance-marketing baseline:
- 9:16, 1080x1920
- headline near top, 1–2 lines
- bold white sans-serif headline
- optional dark translucent card behind headline
- simple bold white captions with a strong black outline
- captions centered in lower third, max 2 lines
- no word-by-word highlighting
- 2-second static end card with logo + one CTA

The default is intentionally neutral. Once a user chooses a visual direction, their profile overrides it.
